# Codex 开发任务提示词

本文件提供可以直接复制给桌面版 Codex 的任务模板。

使用前应确保 Codex 已读取项目根目录的 `AGENTS.md`。

---

## 1. 通用前置提示

每次开始一个新任务时，可以先发送：

```text
请先阅读项目根目录的 AGENTS.md，以及本任务涉及的 docs 文档。

本项目以中文作为主要文档和注释语言。
请严格遵守 coding-guidelines.md 和 comment-guidelines.md。

修改前先检查现有实现，不要重复创建同类模块。
保持 Local-first、Rule-first 和 GitHub Pages 静态部署原则。

完成后请：
1. 总结修改的文件；
2. 说明关键实现；
3. 列出仍存在的限制；
4. 运行并报告 pnpm typecheck、pnpm test、pnpm build 的结果。
```

## 2. PDF 导入任务

```text
请完成 v0.1 的 PDF 批量导入功能。

先阅读：
- docs/product/v0.1-feature-spec.md
- docs/product/ui-interaction-spec.md
- docs/development/v0.1-development-plan.md
- docs/development/coding-guidelines.md
- docs/development/comment-guidelines.md

要求：
- 支持点击多选 PDF；
- 支持拖拽多个 PDF；
- 自动忽略非 PDF 文件并给用户提示；
- 不上传任何文件；
- 上传组件只负责文件交互，不写发票解析规则；
- 保持代码模块化；
- 对 File API 中值得学习的部分增加简洁中文注释。

不要实现 OCR、后端、数据库。
```

---

## 3. PDF.js 文本提取任务

```text
请完成浏览器本地 PDF 文本提取模块。

要求：
- 使用 PDF.js；
- File.arrayBuffer() 读取本地文件；
- 逐页调用文本层读取能力；
- 按页顺序合并；
- 单文件失败返回可理解错误；
- 能识别文本量明显过少的情况；
- 不上传文件；
- 不把 PDF.js 逻辑写在 React 页面中；
- 补充单元测试或可测试的纯函数边界；
- 使用中文学习型注释解释关键浏览器 API 和 PDF.js 行为。
```

---

## 4. 发票解析任务

```text
请完善 packages/invoice-core 的 v0.1 发票解析能力。

优先完成：
- 文本标准化；
- 文件名日期和名称解析；
- 发票号码；
- 开票日期；
- 不含税金额；
- 税额；
- 价税合计。

要求：
- 每个字段尽量拆成独立函数；
- 明确标签优先于启发式；
- 启发式只能作为 fallback；
- 复杂正则必须有中文说明；
- 单个字段失败不能导致整张发票失败；
- 不可靠字段允许为空；
- 增加覆盖典型情况和异常情况的单元测试。
```

---

## 5. 校验任务

```text
请实现发票数据校验与重复检测。

要求：
- 不含税金额 + 税额 与 价税合计进行校验；
- 允许 0.01 元以内误差；
- 缺少金额时返回“无法校验”；
- 使用发票号码检测重复；
- 重复记录不自动删除；
- 用户修改金额或发票号码后可以重新计算；
- 校验逻辑放 invoice-core，不放 React 组件。
```

## 6. 结果表格任务

```text
请完成 v0.1 发票结果表格。

要求：
- 使用统一字段定义；
- 支持可编辑单元格；
- 支持删除单行；

```

## 7. 导出列任务

```text
请完成 v0.1 自定义导出列功能。

要求：
- 所有选项来自统一字段注册表；
- 按文件信息、发票信息、购销方、金额、其他分组；
- 支持全选；
- 支持恢复默认；
- 默认选择合理；
- LocalStorage 保存用户偏好；
- Excel 和 CSV 必须使用同一个选中字段列表；
- 至少保留一个字段才能导出；
- 不单独再维护另一套“导出字段”常量。
```

## 8. 导出任务

```text
请完成 Excel 和 CSV 导出。

Excel：
- xlsx；
- 中文表头；
- 只导出用户选中的字段；
- 金额保持数字类型；
- 两位小数格式；
- 合计行；
- 合理列宽；
- 文件名“发票汇总表.xlsx”。

CSV：
- UTF-8 BOM；
- 正确处理逗号、双引号和换行；
- 使用与 Excel 完全一致的字段选择；
- 文件名“发票汇总表.csv”。

导出全部在浏览器本地完成。
```

## 9. 代码审查提示

一个阶段完成以后，可以使用：

```text
请对刚刚完成的代码进行一次代码审查。

重点检查：
- 是否违反 AGENTS.md；
- 是否破坏 Local-first；
- 是否存在重复字段配置；
- 是否把业务逻辑写进 React 页面；
- 是否滥用 any；
- 是否存在无意义注释；
- 复杂正则是否有中文说明；
- 是否有可拆分的超大组件；
- 是否有状态可以由已有数据计算却被重复保存；
- 是否影响 GitHub Pages 静态构建；
- 是否缺少测试。

发现问题后直接修复，再运行 typecheck、test 和 build。
```
