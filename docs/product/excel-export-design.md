# Excel 导出设计

## 1. 目标

Invoice Workbench 的 Excel 导出不仅要“能打开”，还应该可以直接用于日常报销、核对、归档和二次统计。

v0.1 的 Excel 导出遵循：

> 数据正确优先，阅读体验其次，样式克制统一。

## 2. 技术实现

Excel 导出使用 ExcelJS，并且只在用户点击“导出 Excel”时动态加载。

这样可以同时获得：

- 完整单元格样式；
- 冻结视图；
- 自动筛选；
- 更明确的列宽与数字格式控制；
- 浏览器端 `writeBuffer()` 导出。

PDF 和结构化发票数据仍然只在浏览器本地处理，Excel 导出不会引入服务器上传。

## 3. 默认视觉规范

### 表头

- 深绿色背景，与网站主色保持一致；
- 白色粗体；
- 水平 / 垂直居中；
- 高度略高于普通数据行。

### 正文

- 字体：微软雅黑；
- 金额右对齐；
- 日期、状态、税率居中；
- 普通文本左对齐；
- 轻量斑马纹增强大量记录阅读；
- 使用浅灰细边框，不使用过重网格线。

### 金额

Excel 中保持真正数值类型：

```text
#,##0.00
```

负数金额使用红色数字，方便红字发票快速识别。

### 状态

状态列可以使用轻量语义颜色：

- 成功 / 已确认 / 通过：绿色；
- 待复核 / 未确认：黄色；
- 失败 / 异常 / 重复：红色；
- 其他状态：灰色。

颜色只用于辅助阅读，不改变实际导出值。

## 4. 冻结与筛选

默认冻结：

```text
第一行：字段表头
第一列：当前导出的第一列
```

因此大量发票横向和纵向滚动时仍然能够看到表头和关键第一列。

第一行同时开启 Excel 自动筛选，可以在 Excel 中继续按日期、公司名称、状态等字段筛选。

## 5. 列宽

列宽根据表头和实际数据估算，并设置上限：

- 日期、状态等保持紧凑；
- PDF 文件名和公司名称允许更宽；
- 项目名称和备注允许更大宽度；
- 超长内容不会无限撑宽整张工作表。

## 6. 合计行

最后一行继续保留金额合计，并使用浅绿色背景和较明显的顶部边框。

金额合计仍然是数值，不转换成格式化字符串。

## 7. CSV

CSV 是纯文本格式，不支持字体、冻结、背景色等样式。

因此：

- Excel 导出负责“正式报表体验”；
- CSV 保持轻量、通用和机器可读；
- 两种格式继续使用完全相同的字段选择与数据范围。
