# 字段目录与导出列设计

## 1. 设计目标

所有“表格字段”和“可导出字段”都应来自统一字段定义，而不是在界面、Excel、CSV 中重复硬编码。

v0.1 的字段注册表定义在：

```text
packages/invoice-core/src/fields.ts
```

用户可以通过复选框自由决定导出哪些列。

## 2. 字段分类

### 文件追溯字段

| 字段键 | 中文名 | 默认导出 | 来源 | 说明 |
|---|---|---:|---|---|
| `sourceFileName` | PDF 文件名 | 是 | 文件 | 永远保留，方便回查原始文件 |
| `fileDate` | 日期 | 是 | 文件名 | 从约定文件名中解析 |
| `fileDisplayName` | 名称 | 是 | 文件名 | 从约定文件名中解析 |

### 发票基本信息

| 字段键 | 中文名 | 默认导出 | 来源 |
|---|---|---:|---|
| `invoiceType` | 发票类型 | 否 | 发票正文 |
| `invoiceNumber` | 发票号码 | 是 | 发票正文 |
| `issueDate` | 开票日期 | 是 | 发票正文 |

### 销售方与购买方

| 字段键 | 中文名 | 默认导出 |
|---|---|---:|
| `sellerName` | 销售方名称 | 否 |
| `sellerTaxId` | 销售方税号 | 否 |
| `buyerName` | 购买方名称 | 否 |
| `buyerTaxId` | 购买方税号 | 否 |

### 金额字段

| 字段键 | 中文名 | 默认导出 | 数据类型 |
|---|---|---:|---|
| `amountExcludingTax` | 不含税金额 | 是 | 金额 |
| `taxAmount` | 税额 | 是 | 金额 |
| `amountIncludingTax` | 价税合计 | 是 | 金额 |
| `taxRate` | 税率 | 否 | 文本 |

### 业务字段

| 字段键 | 中文名 | 默认导出 |
|---|---|---:|
| `itemName` | 项目名称 | 否 |
| `remark` | 备注 | 是 |

### 质量与校验字段

| 字段键 | 中文名 | 默认导出 | 说明 |
|---|---|---:|---|
| `parseStatus` | 解析状态 | 否 | `success / review / failed` |
| `confidence` | 置信度 | 否 | 0～1 |
| `duplicateStatus` | 重复状态 | 否 | `duplicate / unique / unknown` |
| `amountValidation` | 金额校验 | 否 | `valid / invalid / unknown` |

## 3. 导出列交互

推荐行为：

1. 页面上显示“导出列”设置区。
2. 每个字段通过复选框控制是否导出。
3. 默认勾选常用列。
4. 用户选择保存到 `localStorage`。
5. Excel 与 CSV 使用同一份选中字段列表。
6. 后续支持拖拽调整导出顺序。
7. 后续支持保存“导出模板”。

示例：

```text
☑ PDF文件名
☑ 日期
☑ 名称
☑ 发票号码
☑ 不含税金额
☑ 税额

☐ 购买方名称
☐ 购买方税号
☐ 税率
☐ 项目名称
☑ 备注
```

## 4. 字段新增规范

新增字段时必须：

1. 在 `InvoiceRecord` 中定义。
2. 在 `EXPORT_FIELDS` 中登记。
3. 定义标签、类型、默认导出状态。
4. 决定是否可编辑。
5. 更新本文件。
6. 为解析逻辑补充测试。

## 5. “日期”和“名称”的特殊说明

当前需求中的“日期”和“名称”可以来源于文件名，例如：

```text
2026.08.14-京东-128.50元.pdf
```

可解析为：

```text
fileDate        = 2026-08-14
fileDisplayName = 京东-128.50元
```

这与发票正文中的 `issueDate`、`sellerName` 是不同概念，不应混为同一字段。

后续可以让用户配置文件名模板，使不同命名习惯都能被识别。
