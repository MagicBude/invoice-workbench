# v0.1 验收清单

本清单用于判断 v0.1 是否达到“可以实际整理发票”的最低标准。

---

## 1. 工程检查

- [ ] `pnpm install` 正常。
- [ ] `pnpm typecheck` 通过。
- [ ] `pnpm test` 通过。
- [ ] `pnpm build` 通过。
- [ ] Next.js 静态导出仍然生成 `out/`。
- [ ] GitHub Pages 工作流未被破坏。

---

## 2. PDF 导入

- [ ] 点击可以选择一个 PDF。
- [ ] 点击可以一次选择多个 PDF。
- [ ] 可以拖拽一个 PDF。
- [ ] 可以拖拽多个 PDF。
- [ ] 非 PDF 文件不会进入解析队列。
- [ ] 非 PDF 文件有明确提示。
- [ ] 一个 PDF 失败不会阻塞其他文件。
- [ ] 用户能够看到处理进度。

---

## 3. 本地处理

- [ ] PDF 使用浏览器本地读取。
- [ ] 默认没有网络上传请求。
- [ ] 多页 PDF 可以按顺序提取文本。
- [ ] 文本层读取失败有明确状态。
- [ ] 文本明显过少时可以进入待复核状态。

---

## 4. 字段解析

至少验证以下字段：

- [ ] PDF 文件名。
- [ ] 日期。
- [ ] 名称。
- [ ] 发票号码。
- [ ] 开票日期。
- [ ] 不含税金额。
- [ ] 税额。
- [ ] 价税合计。

对于当前尚无可靠规则的字段：

- [ ] 不会为了填值而产生明显猜测结果。
- [ ] 允许保持为空。

---

## 5. 金额校验

准备：

```text
不含税金额：100.00
税额：13.00
价税合计：113.00
```

- [ ] 校验为通过。

准备异常值：

```text
不含税金额：100.00
税额：13.00
价税合计：120.00
```

- [ ] 校验为异常。

缺少任一关键金额：

- [ ] 显示无法校验，而不是错误通过。

---

## 6. 重复检测

准备两条相同发票号码：

- [ ] 两条记录均标记重复。
- [ ] 不自动删除其中任何一条。

修改其中一条发票号码：

- [ ] 重复状态立即重新计算。

---

## 7. 表格编辑

- [ ] 用户可以修改字段值。
- [ ] 修改金额后金额校验更新。
- [ ] 修改发票号后重复检测更新。
- [ ] 删除行后总数更新。
- [ ] 删除行后金额合计更新。
- [ ] 删除行后重复状态更新。
- [ ] 长文件名能够查看完整内容。
- [ ] 大量列时支持横向滚动。

---

## 8. 导出列

- [ ] 可以勾选字段。
- [ ] 可以取消字段。
- [ ] 可以全选。
- [ ] 可以恢复默认。
- [ ] 字段按类别组织。
- [ ] 刷新页面后选择仍然保留。
- [ ] 没有选中字段时不能导出。
- [ ] Excel 和 CSV 使用相同字段顺序。

---

## 9. Excel

- [ ] 能生成 `.xlsx`。
- [ ] 中文正常。
- [ ] 表头正确。
- [ ] 只包含选中字段。
- [ ] 金额单元格为数字而不是纯文本。
- [ ] 金额显示两位小数。
- [ ] 包含金额合计。
- [ ] 列宽基本可读。
- [ ] 文件名为“发票汇总表.xlsx”。

---

## 10. CSV

- [ ] 能生成 `.csv`。
- [ ] Excel 打开中文不乱码。
- [ ] 只包含选中字段。
- [ ] 逗号字段正确转义。
- [ ] 双引号字段正确转义。
- [ ] 换行字段正确转义。
- [ ] 文件名为“发票汇总表.csv”。

---

## 11. 隐私

使用浏览器开发者工具 Network 检查：

- [ ] 添加 PDF 时没有把文件上传到网络。
- [ ] 解析过程中没有隐式上传。
- [ ] 导出过程中没有上传。
- [ ] 页面有明确本地处理说明。

---

## 12. 中文体验

- [ ] 用户可见主要文案为中文。
- [ ] 错误提示为中文。
- [ ] 空状态为中文。
- [ ] 技术术语只在必要时使用英文。
- [ ] 不存在明显中英文混杂的用户界面。

---

## 13. 发布判定

只有当：

```text
核心流程通过
+ 没有阻断级错误
+ typecheck/test/build 通过
+ 本地处理原则未被破坏
```

才将 v0.1 视为达到可提交 / 可部署状态。

---

## 14. 批量筛选与人工复核

- [ ] 点击“全部”显示当前批次所有记录。
- [ ] 点击“待复核”只显示尚未人工确认的待复核记录。
- [ ] 点击“人工已确认”只显示人工确认记录。
- [ ] 点击“重复记录”能筛出重复发票号码。
- [ ] 点击“金额异常”能筛出金额关系异常记录。
- [ ] 搜索文件名可以立即过滤结果。
- [ ] 搜索发票号可以立即过滤结果。
- [ ] 搜索购销方名称可以立即过滤结果。
- [ ] 文件日期、开票日期和金额排序正确。
- [ ] 排序不会修改原始记录内容。
- [ ] 点击“确认已复核”不会改变自动解析状态。
- [ ] 人工已确认记录再次编辑后自动恢复为未确认。
- [ ] “上一待处理 / 下一待处理”会跳过已经人工确认的记录。
- [ ] “当前筛选”导出的记录数量与当前表格一致。
- [ ] “全部”导出不受搜索与筛选条件影响。

---

## 15. Stage 6 UI 与性能收尾

- [ ] 桌面端统计卡片在常见宽度下保持紧凑布局。
- [ ] 浏览器缩放导致视口变小时，统计卡片能合理降级为 4 列或 2 列。
- [ ] 已有解析结果时上传区域自动变为紧凑模式。
- [ ] “显示与导出字段”默认收起。
- [ ] 展开 / 收起字段设置不会影响已解析数据。
- [ ] 字段面板展开状态可以保存在当前浏览器。
- [ ] 筛选区与结果表格之间不再被大块字段设置长期隔开。
- [ ] 批量导入过程中结果按小批次刷新。
- [ ] 批次结束后统一重复检测仍然正确。
- [ ] 参照 `performance-checklist.md` 完成大批量验证。
