# 未来后端能力与部署方向

## 什么时候才需要后端

出现以下需求时再引入后端：

- 扫描 PDF OCR
- AI 辅助解析
- 云端历史记录
- 多端同步
- 多用户协作
- 企业权限
- 后台异步任务

## 推荐形态

```text
GitHub 仓库
      │
      ├── apps/web → GitHub Pages / 静态托管
      │
      └── apps/api → FastAPI
                         │
                         ├── OCR
                         ├── AI 辅助解析
                         ├── 文件存储
                         └── 数据库
```

## API 设计原则

即使未来存在后端，也不要把标准电子发票全部强制上传。

推荐：

```text
本地解析成功      → 不上传
本地结果需复核    → 用户可主动选择云端处理
无文本层          → 用户可主动选择 OCR
```

后端是补充能力，不应破坏 Local-first（本地优先）的基础体验。
