# v0.1.0 发布检查清单

本文件用于 Invoice Workbench 第一个正式版本 `v0.1.0` 发布前的最终检查。

## 1. 工程质量

- [ ] `pnpm typecheck` 全部通过。
- [ ] `pnpm test` 全部通过。
- [ ] `pnpm build` 全部通过。
- [ ] GitHub Actions Pages 工作流成功。
- [ ] GitHub Pages 正式地址可以打开。

## 2. 核心工作流

- [ ] 批量导入 PDF。
- [ ] PDF.js 本地文本提取。
- [ ] 发票基础字段解析。
- [ ] 购销方名称 / 税号解析。
- [ ] 金额与税率解析。
- [ ] 项目名称解析。
- [ ] 金额校验。
- [ ] 重复检测。
- [ ] 搜索 / 筛选 / 排序。
- [ ] 单张 PDF 对照复核。
- [ ] 人工确认。
- [ ] Excel / CSV 导出。
- [ ] 当前筛选结果导出。

## 3. 真实样本回归

- [ ] 普通电子发票。
- [ ] 增值税专用发票。
- [ ] 双栏购销方版式。
- [ ] 多商品明细。
- [ ] 红字 / 负数金额样本（如已有）。
- [ ] 无文本层 PDF 能正确提示失败或待后续 OCR。
- [ ] 不可靠字段宁可为空，不产生明显错误猜测。

## 4. UI 与中文体验

- [ ] 桌面端统计卡片保持紧凑布局。
- [ ] 有数据后上传区自动缩小。
- [ ] 字段设置默认收起，结果表格更靠近筛选区。
- [ ] 字段设置可以正常展开 / 收起。
- [ ] 主要用户文案全部为中文。
- [ ] 长表格支持独立纵向 / 横向滚动。
- [ ] 固定表头与固定文件名列正常。

## 5. 隐私

使用浏览器 Network 面板确认：

- [ ] 导入 PDF 不上传原文件。
- [ ] 解析过程不上传原文件。
- [ ] PDF 复核预览使用本地 Object URL。
- [ ] Excel / CSV 导出在浏览器本地完成。

## 6. 大批量验证

按照 [`../testing/performance-checklist.md`](../testing/performance-checklist.md) 至少完成一次 200 张级别验证。

- [ ] 大批量导入完成。
- [ ] 搜索 / 筛选 / 排序可用。
- [ ] 页面没有崩溃。

## 7. 文档

- [ ] README 与实际功能一致。
- [ ] CHANGELOG 已整理。
- [ ] 路线图已更新。
- [ ] GitHub Pages 部署文档有效。
- [ ] v0.1 当前限制写清楚。

## 8. 发布操作

最终确认后：

```bash
git tag -a v0.1.0 -m "Invoice Workbench v0.1.0"
git push origin v0.1.0
```

随后在 GitHub 创建 Release：

```text
Tag: v0.1.0
Title: Invoice Workbench v0.1.0
```

Release Notes 应重点说明：

- 浏览器本地处理 PDF。
- 当前主要支持带文本层的电子发票。
- 支持批量解析、校验、人工复核和 Excel / CSV 导出。
- OCR 尚未进入 v0.1。
