# 项目发展路线图

## v0.1 — 本地优先可用版本

目标：完成无需后端即可使用的发票整理闭环，并适合一次处理几十到几百张电子 PDF 发票。

### 已完成

- [x] Monorepo 基础框架
- [x] Next.js Static Export
- [x] GitHub Pages 自动部署
- [x] PDF 批量导入
- [x] PDF.js 浏览器本地文本提取
- [x] PDF 视觉顺序恢复
- [x] 发票号码 / 日期 / 金额解析
- [x] 购销方名称与税号解析
- [x] 税率与项目名称基础解析
- [x] 金额关系校验
- [x] 重复发票检测
- [x] 自定义显示与导出字段
- [x] Excel / CSV 导出
- [x] PDF 与结构化字段并排复核
- [x] 搜索、状态筛选和常用排序
- [x] 人工已确认状态
- [x] 上一 / 下一待处理记录
- [x] 导出全部或当前筛选结果
- [x] 用真实发票持续做回归验证
- [x] 核心解析和导出自动化测试

### v0.1 发布前收尾

- [ ] 继续验证更多数电票版式
- [ ] 统一低置信度、金额异常、重复等提示文案
- [ ] 大批量文件性能验证
- [ ] 完成 v0.1 最终验收清单
- [ ] 发布 `v0.1.0` Tag / Release

### 可在 v0.1 后续小版本增加

- [ ] 用户可配置文件名规则
- [ ] 导出列拖拽排序
- [ ] 保存多套导出模板
- [ ] Web Worker 拆分耗时计算

---

## v0.2 — OCR 与更多票据覆盖

目标：处理无文本层的扫描 PDF 和当前不能由 PDF.js 直接解析的文件。

- [x] 无文本层检测
- [ ] OCR 入口与用户确认提示
- [ ] 优先评估浏览器本地 OCR
- [ ] 如本地方案不足，再评估 FastAPI + PaddleOCR
- [ ] 上传文件的隐私提示与临时文件清理
- [ ] OCR 结果继续进入现有 `invoice-core`
- [ ] 行程单 / 非标准票据分类
- [ ] 折扣、特殊税率与更多异常版式

---

## v0.3 — AI 辅助与高级能力

只在规则和 OCR 仍不能稳定解决低置信度场景时加入。

- [ ] 只对低置信度记录调用 AI
- [ ] 结构化 Schema 输出
- [ ] 调用成本控制
- [ ] 用户明确可见的云端处理说明
- [ ] 更复杂的文档类型识别
