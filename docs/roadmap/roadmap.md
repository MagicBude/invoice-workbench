# 项目发展路线图

## v0.1 — 本地优先基础版本

目标：完成无需后端即可使用的发票整理闭环。

### P0：基础闭环

- [x] Monorepo 基础框架
- [x] Next.js Static Export 配置
- [x] GitHub Pages Actions 基础配置
- [x] `invoice-core` 数据模型
- [x] 可导出字段统一注册表
- [x] PDF 批量导入界面骨架
- [x] PDF.js 本地文本提取入口
- [x] 基础发票号码 / 日期 / 金额规则
- [x] 金额关系校验
- [x] 基础重复检测
- [x] 可选导出列
- [x] Excel / CSV 导出入口
- [ ] 用真实发票样本系统性验证解析准确率
- [ ] 完善销售方 / 购买方字段解析
- [ ] 完善数电票多版式规则
- [ ] 补充更多单元测试

## v0.2 — 复核体验

- [ ] PDF 与结构化字段并排复核
- [ ] 低置信度高亮
- [ ] 失败原因分类
- [ ] 用户可配置文件名规则
- [ ] 导出列排序
- [ ] 保存导出模板
- [ ] 批量处理性能优化
- [ ] Web Worker 拆分

## v0.3 — 发票覆盖能力

- [ ] 红字 / 负数发票

- [ ] 只针对低置信度或 OCR 结果调用 AI

## v1.0 — 稳定版本
